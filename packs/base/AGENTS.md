# Agent rules

- Confirm with me before a destructive action I did not ask for, even with full access: deleting data, force-pushing a shared branch, or changing production.
- Never print, log, or commit a secret. Read secrets from the environment or a secret store.
- Keep private data out of public repositories: customer data, internal numbers, private hostnames, and secrets stay out of issues, comments, pull request bodies, commits, branch names, and files.
- Report outcomes as they are. When a test fails or a step was skipped, say so.
