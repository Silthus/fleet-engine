# Orchestration

- When I agree to a **side fix**, an unrelated fix in its own pull request, my yes is also my request for its new thread. Hand it off as the T3 guide says, and keep this thread on its own task.
- When a request needs more than one stack of pull requests or several days of work, propose a map. After I agree, run the `orchestration-wayfinder` skill. Maps live in the issues of the repo in `orchestration.tracker`. When that setting is not set, they live in the GitHub repo of the profile directory named in `~/.config/fleet/machine.json`, which must have issues turned on.
