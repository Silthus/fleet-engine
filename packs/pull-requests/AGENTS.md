# Pull requests

- When I ask you to fix or build something, finish with a draft pull request, or a stack of them, ready for my review. The `full-stop` skill runs that flow. A repo's own `AGENTS.md` can replace it.
- I mark pull requests ready for review myself. Keep every pull request a draft unless I say "full send", "ship it to production", or "stamp it". Those words run the `full-send` and `stamp-pr` skills.
- Format every pull request link as [#1234](https://url-to-pr).
- Read the **PR workflow**, `~/.agents/guides/pull-requests.md`, before you build toward a pull request, when you review, prove, or babysit one, and when I say one is ready.
- Read the **Standing rules**, `~/.agents/guides/standing-rules.md`, before you ask me to accept a proof gap or decide a review round.
